## 매일 저장할 내용

1. **오늘의 학술 용어와 근거**: 핵심 용어 1개, 정확한 정의, 중요한 구별 1개, 실제 확인한 원문 2~3개.
2. **고객에게 설명하는 영어**: 핵심 표현 1개와 확장 표현 5개, 청중별 변형을 포함한 예문 6~8개, 한국어 풀이.
3. **오늘의 한 문제**: 핵심 표현과 선택 표현으로 답하는 가상의 고객 질문 1개.

주 자료는 **OpenAI·Anthropic·NVIDIA·Microsoft·Google·AWS**의 공식 연구·엔지니어링·기술 블로그, 연구/기술 보고서, 논문 해설, 근거 있는 Best Practices, 공식 기술 발표 자료에서 선정합니다. Microsoft·AWS·Google로 제한하지 않으며, OpenAI·Anthropic·NVIDIA도 동등한 정규 주 자료 후보입니다. Meta·IBM 등 다른 빅테크의 공식 글도 주제와 품질 기준에 맞으면 활용합니다.

OpenAI의 Research·기술 보고서, Anthropic의 Research·Engineering, NVIDIA의 Research·Technical Blog·GTC 발표 자료를 포함합니다. NVIDIA 자료에서는 추론, 양자화, 지식 증류, KV cache, 배치 처리, GPU·분산 서빙 등의 개념도 다룹니다. 회사 이름보다 정확한 정의·작동 원리·설계 선택·실험·한계가 설명되어 있는지를 우선합니다. 단순 홍보나 API 사용법만 있는 문서는 주 자료로 삼지 않습니다.

매번 주 자료와 교차 확인 자료의 본문을 실제로 읽어 총 2~3개의 출처를 연결합니다. 필요한 경우 원 논문으로 정의와 연구 결과를 확인하며, 공급업체의 설명·권고와 동료심사를 거친 학술적 결과는 구분합니다. 성능 수치는 확인 가능한 하드웨어·모델·측정 조건·비교 기준과 함께 해석합니다. 매일 모든 회사를 포함하지 않고 주제 적합성을 우선하며 출처 편중을 피합니다.

## 저장 구조와 실행 방식

```text
learning/
  README.md
  ARCHIVE.md
  index.json
  lessons/
    README.md
    YYYY/MM/YYYY-MM-DD.md
  records/
    README.md
    YYYY/MM/YYYY-MM-DD.json
```

한국 시간(Asia/Seoul) 날짜를 사용합니다. 같은 날의 재시도는 같은 경로를 사용하여 중복 게시를 피합니다. Markdown은 읽기용 본문이고 JSON은 표현 검색·재사용용 구조화 자료입니다. JSON으로 저장했다는 사실은 모델 학습이나 학습 완료를 뜻하지 않습니다.

기존 ChatGPT 예약 작업이 매일 오전 7시 15분에 학습 자료를 준비하고, 연결된 GitHub 도구로 이 저장소의 `main` 브랜치에 저장하도록 구성합니다. 이 저장소 자체가 스케줄러는 아니며 별도의 GitHub Actions 예약이나 API 키를 요구하는 생성 스크립트를 설치한 것은 아닙니다. 실행에는 예약 환경의 GitHub 접근·쓰기 권한이 필요합니다. 실행 시작 시각과 생성·커밋 완료 시각은 다를 수 있습니다.

**초기 설정일: 2026-10-25.** 초기 설정 커밋에는 안내와 빈 색인만 포함합니다. 과거 대화의 학습 자료를 자동으로 소급 이관하거나 오늘의 수업이 이미 저장되었다고 표시하지 않습니다. 이후 실제 저장된 수업만 날짜별 목록에 추가합니다.
