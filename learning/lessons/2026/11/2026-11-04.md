# No Smart Intelligent | 2026.11.04 (수) — In-context Learning

**Today's Key Expression: “Use examples in the prompt to guide predictions without updating model weights.”**

약 10분 학습 · 핵심 1개 + 확장 5개 · 청중별 예문 2개

## 1. 오늘의 학술 용어와 근거

**In-context learning (ICL) — 문맥 내 학습.** 모델이 현재 프롬프트에 제공된 입력–라벨 예시를 참고하여 새로운 입력을 처리하는 방식으로, 이 추론 과정에서 모델의 학습된 가중치를 업데이트하지 않습니다. 모델은 예시 속 대응 관계를 활용할 수도 있고, 사전 학습으로 익힌 라벨 의미를 이용할 수도 있습니다. 이는 구체적인 과제에 대한 few-shot ICL 정의이며, Anthropic의 2022년 연구에서는 문맥이 길어질수록 토큰 예측 손실이 낮아지는 더 넓은 의미도 사용합니다. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/) · [S2](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/index.html)

**관련 용어:** **Few-shot prompting**은 몇 개의 입출력 예시를 프롬프트에 넣는 방식이고, **Fine-tuning**은 학습을 통해 모델 가중치를 바꾸는 작업입니다.

**가상 업무 사례 — 구매 문의 분류:** 구매팀이 예시 두 개를 제공한다고 가정해 봅니다. “원산지증명서 요청 → DOC”, “도착 일정 확인 → LOG”를 제시한 뒤 새 문의를 분류하게 하는 것입니다. 모델이 DOC와 LOG의 대응 관계를 예시에서 활용할 가능성은 있지만, 올바르게 따르는지 별도 문의로 검증해야 합니다.

**혼동하기 쉬운 점:** 예시 몇 개로 현재 응답을 유도하는 것이 곧 영구 재학습은 아닙니다. **11월 1일 복습 표현** “Train a smaller student model using guidance from a larger teacher”는 학생 모델의 가중치를 학습시키는 지식 증류를 가리킵니다. 반대로 ICL은 추론 중 가중치를 고정합니다.

**원문 요지 → 재작성:** Google Research는 ICL 결과에 *사전 의미 지식*과 *문맥 속 입력–라벨 대응 관계*가 모두 작용할 수 있다고 설명합니다. 그래서 오늘은 단순한 “the model learns” 대신 **“Use examples in the prompt to guide predictions without updating model weights”**라고 표현합니다. Google의 실험은 특정 모델군과 NLP 분류 과업에 관한 연구 결과이며 모든 모델의 동작을 보장하지 않습니다. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/)

**확인한 자료 (열람: 2026-11-04):**

- **[S1] Google Research · Jerry Wei, Denny Zhou · *Larger language models do in-context learning differently* · 2023-05-15 · 연구 블로그/연구 해설.** Few-shot ICL, 의미적 사전 지식과 입력–라벨 대응 관계, 라벨 변경 실험의 설명을 확인했습니다. [원문](https://research.google/blog/larger-language-models-do-in-context-learning-differently/)
- **[S2] Anthropic / Transformer Circuits · Catherine Olsson 외 · *In-context Learning and Induction Heads* · 2022-03-08 · 저자 연구 원문(동료심사 여부 미확인).** 모델 재학습 없는 문맥 적응 및 ICL의 더 넓은 측정 정의를 교차 확인했습니다. 대형 모델의 induction head 설명은 저자들의 가설이며 확정적 인과 설명으로 사용하지 않습니다. [원문](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/index.html)

## 2. 고객에게 설명하는 영어

다음 여덟 문장은 확인한 개념을 바탕으로 새로 작성한 설명용 재작성·가상 사례입니다.

**⭐ 1. Use examples in the prompt to guide predictions without updating model weights**

> In-context learning uses examples in the prompt to guide a model's predictions without updating its weights.

문맥 내 학습은 모델의 가중치를 변경하지 않고 프롬프트 속 예시를 이용해 예측을 유도합니다. **사용:** ICL의 정의와 모델 재학습의 차이를 설명할 때. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/) · [S2](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/index.html)

**2. Provide input–label pairs before a new case**

> We provide labeled examples of purchase inquiries before asking the model to classify a new message.

새 메시지의 분류를 요청하기 전에 구매 문의의 라벨이 붙은 예시를 제공합니다. **사용:** 몇 개의 예시를 프롬프트에 넣는 사용 방식을 설명할 때. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/)

**3. Infer input–label mappings from the examples**

> The model can infer which inquiry descriptions map to each label from the examples in its context.

모델은 문맥 속 예시를 보고 어떤 문의 설명이 어느 라벨에 대응하는지 추론할 수 있습니다. **사용:** 예시가 입력과 출력의 관계를 전달하는 원리를 설명할 때. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/)

**4. Distinguish prior knowledge from demonstrated mappings**

> We distinguish mappings inferred from the examples from meanings the model already associates with label names.

예시에서 추론한 대응 관계와 모델이 라벨 이름에 이미 연결해 둔 의미를 구분합니다. **사용:** 모델이 예시를 따르는지, 사전 지식으로 답하는지 논의할 때. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/)

**5. Check whether the model follows unfamiliar labels**

> We check whether the model assigns codes such as A17 and B24 by following the examples rather than guessing from label names.

모델이 라벨 이름을 추측하는 대신 예시를 따라 A17, B24 같은 코드에 분류하는지 확인합니다. **사용:** 임의의 코드나 업무 전용 라벨에서도 예시를 따르는지 테스트할 때. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/)

**6. Compare performance with and without in-context examples**

> We would compare classification accuracy on held-out inquiries with and without demonstrations in the prompt.

별도 평가 문의에서 프롬프트에 예시가 있을 때와 없을 때의 분류 정확도를 비교하겠습니다. **사용:** 실무 도입 전 예시의 효과를 검증하는 평가 방식을 제안할 때. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/) · [S2](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/index.html)

**청중별 변형 — 임원/비전공 현업**

> We can illustrate a new inquiry classification rule with examples instead of training a new model, but we still need to validate the results.

새 모델을 학습시키지 않고 예시로 문의 분류 규칙을 보여줄 수 있지만, 결과 검증은 여전히 필요합니다. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/)

**청중별 변형 — 기술팀**

> We would freeze the model weights, vary the input–label examples in the prompt, and measure accuracy on unseen inquiries.

모델 가중치를 고정하고 프롬프트의 입력·라벨 예시를 달리하여 미확인 문의의 정확도를 측정하겠습니다. [S1](https://research.google/blog/larger-language-models-do-in-context-learning-differently/) · [S2](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/index.html)

## 3. 오늘의 한 문제

**가상 고객 상황 — 제조 설비 사고 티켓 분류.** 제조기업이 사고 티켓을 자체 심각도 코드 R1, R2로 분류하려 합니다. 고객은 프롬프트에 코드별 예시 몇 개를 제공하려 하지만, 이 방식이 모델을 영구적으로 학습시키는 것인지 궁금해합니다.

**Customer Question**

> If we show the assistant a few examples of our R1 and R2 incident codes, will it permanently learn our categories, and how would you test whether it follows the examples?

**Your Mission:** 영어 **3~5문장, 약 40~70단어** 또는 **30~45초**로 답하세요. 필수 표현 **“Use examples in the prompt to guide predictions without updating model weights”**을 상황에 맞게 변형해 사용하고, 다음 중 **하나만** 선택하세요: **“Check whether the model follows unfamiliar labels”** 또는 **“Compare performance with and without in-context examples.”** 예시를 활용하는 현재 추론과 모델 가중치의 영구적 업데이트를 구분하고, 낯선 사고 티켓에 대한 검증 방법이나 한계를 포함하세요. 검증하지 않은 분류 정확도를 단정하지 마세요.
