# No Smart Intelligent | 2026.10.28 (수) — Key-Value Cache (KV cache)

**Today's Key Expression: “Reuse cached key and value vectors instead of recomputing them.”**

**학습 목표:** 약 10분 · 핵심 표현 1개 + 확장 5개 · 예문 8개 · 고객 질문 1개

## 1. 오늘의 학술 용어와 근거

**Key-Value Cache (KV cache) — 키·값 캐시.** 자기회귀 방식의 인과적 어텐션 Transformer는 새 토큰을 생성할 때 이전 토큰에서 계산한 키(Key)와 값(Value)을 참조합니다. KV 캐시는 이 중간 벡터를 저장해 재사용함으로써 동일한 계산의 반복을 줄입니다. 대신 캐시를 보관하고 읽는 데 메모리 공간과 대역폭이 필요합니다. [S1][S2]

관련 용어는 **Prefill**(입력 프롬프트를 처리해 초기 KV 상태를 만드는 단계)과 **Decode**(기존 상태를 참조하며 출력을 토큰 단위로 생성하는 단계)입니다. [S1]

**가상 예시:** 긴 품질관리 보고서를 요약하는 LLM은 입력을 처리하면서 키·값 벡터를 만들고, 답변 생성 시 이미 계산한 상태를 재사용할 수 있습니다. **중요한 구별:** KV 캐시는 문서 영구 저장소나 모델이 학습한 장기 기억이 아니라 추론 계산 상태입니다. 요청 간 재사용과 보존 시간은 별도 서빙 구현에 달려 있습니다.

**원문 발췌 — NVIDIA [S2]:** “Caching these key and value elements from previous tokens avoids expensive recomputation”

원문의 ‘재계산 회피’라는 의미를 **“Reuse cached key and value vectors instead of recomputing them”**로 풀어 말했습니다. 재사용할 대상이 과거 토큰의 키·값 벡터라는 기술적 구별을 유지합니다.

## 2. 고객에게 설명하는 영어

다음 영어 예문은 확인한 개념을 토대로 코치가 만든 **설명용 재작성**입니다. 가상 서비스의 성능을 입증하는 문장은 아닙니다.

**E1. ⭐ 핵심 — Reuse cached key and value vectors instead of recomputing them**
> A KV cache lets the model reuse key and value vectors from earlier tokens instead of recomputing them at each generation step.
KV 캐시는 새 토큰을 생성할 때 이전 토큰의 키·값 벡터를 매번 다시 계산하지 않고 재사용하게 합니다. **사용:** KV 캐시의 핵심 작동 원리를 설명할 때. [S1][S2]

**E2. 확장 — Build the cache while processing the input prompt**
> During prefill, the model computes key and value vectors for the input tokens and stores them in the cache.
Prefill 단계에서 모델은 입력 토큰의 키·값 벡터를 계산해 캐시에 저장합니다. **사용:** 입력 프롬프트 처리 과정 설명. [S1]

**E3. 확장 — Read and extend the cache during decoding**
> During decoding, the model reads cached vectors and adds the new token's key and value vectors.
디코딩 중 모델은 저장된 벡터를 읽고 새 토큰의 키·값 벡터를 추가합니다. **사용:** 생성 단계의 캐시 활용 설명. [S1]

**E4. 확장 — Avoid repeating work across decoding steps**
> Reusing the cache avoids calculating the same past-token projections for every new token.
캐시 재사용으로 새 토큰마다 과거 토큰의 동일한 투영 계산을 반복하지 않습니다. **사용:** 반복 계산 감소 메커니즘 설명. [S2]

**E5. 확장 — Trade extra memory for less repeated computation**
> KV caching trades memory capacity and bandwidth for less repeated attention computation.
KV 캐싱은 반복 계산을 줄이는 대신 메모리 용량과 대역폭을 사용합니다. **사용:** 성능과 자원의 절충 관계를 설명할 때. [S1][S2]

**E6. 확장 — Track memory use as context length grows**
> In the proposed service, we would track GPU memory usage as prompts and generated outputs get longer.
제안하는 서비스에서는 프롬프트와 생성 출력이 길어짐에 따라 GPU 메모리 사용량을 추적하겠습니다. **사용:** 운영 평가 설계 제안. [S1][S2]

**청중별 변형 — Business Executive**
> Reusing earlier calculations may help the assistant respond faster, but longer prompts can require more GPU memory.
이전 계산을 재사용하면 응답이 빨라질 수 있지만, 긴 프롬프트는 GPU 메모리를 더 많이 요구할 수 있습니다. [S1][S2]

**청중별 변형 — Technical Team**
> For this causal Transformer design, prefill builds the initial KV cache, and each decoding step reads the saved states and appends new ones.
이 인과적 어텐션 Transformer 설계에서는 prefill이 초기 KV 캐시를 만들고 디코딩 단계마다 저장된 상태를 읽어 새 상태를 추가합니다. [S1][S2]

## 3. 오늘의 한 문제

**가상 상황:** 가상의 보험사 법무팀이 긴 보험약관을 요약하는 LLM 서비스를 검토합니다. 담당자는 KV 캐시가 문서를 계속 기억하는 저장소인지, 어떤 자원 비용이 있는지 묻습니다.

**Customer Question:** “We want to summarize lengthy policy documents. Does a KV cache mean the assistant permanently remembers those documents, and what trade-off does it introduce?”

**과제:** 영어 **3~5문장, 약 40~70단어** 또는 **30~45초**로 답하세요. 필수 표현과 선택 표현 하나만 사용하되 예문을 그대로 복사하지 말고 상황에 맞게 바꿔 보세요.

**필수 표현:** Reuse cached key and value vectors instead of recomputing them

**선택 표현(하나만):** Read and extend the cache during decoding / Trade extra memory for less repeated computation

**포함할 내용:** 캐시가 저장하는 것, 영구 기억과의 차이, 메모리 비용. 실제 서비스 성능을 단정하지 마세요.
