# 구조화 학습 자료

`YYYY/MM/YYYY-MM-DD.json` 파일은 같은 날짜의 학습 Markdown과 짝을 이루는 재사용용 데이터입니다.

핵심 용어와 정의, 여섯 영어 표현, 청중별 예문, 가상의 고객 과제, 실제 원문 출처를 포함합니다. 생성된 카드만 저장하며 사용자 답변·첨삭·점수는 포함하지 않습니다. 이 데이터의 축적은 자동 모델 학습이나 학습자의 숙달을 의미하지 않습니다.
